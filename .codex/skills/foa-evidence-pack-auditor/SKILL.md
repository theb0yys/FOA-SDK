# FOA-SDK Evidence Pack Auditor

## First Actions

1. Open `evidence_pack_template.json`.
2. Fill or mentally map every section before handoff.
3. Require command output, paths, hashes, timestamps, test names, screenshots/logs, approval, or explicit blocked reasons for every claim.
4. Separate static, local, O3DE build, manual Editor/Unity/installer, exact-install runtime, and non-runnable evidence.

## Research

Read root process, deep review, test matrix, and every owner-specific gate.

## Hard Stops

Stop or report blocked if controlling research cannot be named; unclear authority lacks a Deep Research Brief; validation says passed without evidence; skipped gates lack reasons; runtime proof lacks exact-install evidence; or external deployment is claimed without approval, paths, backups, hashes, and timestamps.

## Validation

The pack includes scope, authority, contradictions, impact, compatibility, tests, performance, artifacts/external writes, failures, skipped/blocked lanes, runtime status, and next researched process.

## Runtime Proof

Runtime proof requires exact game/profile, adapter, operation, expected/observed result, diagnostics, and pass/fail. Otherwise state `runtime sign-off not performed`.
