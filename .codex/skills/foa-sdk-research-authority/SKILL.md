# FOA-SDK Research Authority

This gate decides whether work may continue; it is not an implementation skill.

## First Actions

1. State the request.
2. Map the controlling research path.
3. Search exact research, architecture, policies, ADRs, schemas, tickets, gates, owner files, implementation, and tests.
4. Classify each source as controlling, supporting, stale, contradictory, or irrelevant.
5. Record stop conditions before planning edits.

## Research

Minimum authority includes root governance, process workflows, relevant `Research/`, public architecture docs, existing owner implementation/tests, local `AGENTS.md`, and exact O3DE/Unity/runtime profile evidence when those surfaces are involved. A filename match is not authority.

## Hard Stops

Stop if no controlling source exists, conflicts cannot be resolved from a newer or more specific authority, implementation would invent architecture/game facts/native identity/permission/validation meaning, protected data is implicated without permission, or owner is unknown. Produce a Deep Research Brief.

## Validation

Report controlling and supporting files, contradictions/stale sources, checked stop conditions, and the next researched stop/process.

## Runtime Proof

Research authority is static evidence only. Without lawful exact-install Fall of Avalon evidence, state `runtime sign-off not performed`.
