# FOA-SDK PR and Release Captain

## First Actions

1. Check branch/worktree state and exclude unrelated changes.
2. Confirm PR/release scope matches researched owner scope.
3. Check PR template and CODEOWNERS.
4. Require evidence-pack review and DCO-compliant commit.

## Research

Read root governance, review policy, process stack, evidence template, release gates, and applicable owner/migration skills.

## Hard Stops

Stop or report blocked when unrelated changes are mixed, evidence is incomplete, research was unclear without a brief, protected files lack permission, local gates were skipped without reason, CODEOWNERS cannot be enforced, DCO is absent, or release claims lack compatibility/build/artifact/manual/runtime evidence.

## Validation

Report branch/commit/PR/release scope, research/evidence status, local gates, CODEOWNERS, PR checklist, DCO, runtime/artifact proof, and remaining partial/blocked gates.

## Runtime Proof

GitHub handoff creates no runtime proof. State `runtime sign-off not performed` when absent.
