# Protected Files Policy

Protected external data is read-only unless the repository owner grants explicit permission for the exact path and current task.

Protected material includes proprietary Fall of Avalon files, extracted commercial content, private game installations, saves, credentials, signing material, private paths, third-party source without redistribution rights, generated engine output treated as source, and the external pinned O3DE checkout.

Do not copy protected material into FOA-SDK, edit it, publish it, use it as a committed fixture, or derive invented authority from it. Stop, list the affected paths, and request explicit permission when a requested change intersects protected material.
