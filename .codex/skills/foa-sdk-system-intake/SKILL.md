# FOA-SDK System Intake

## Research To Read

Start with root governance, `SYSTEM_INDEX.md`, protected policy, architecture/docs, task-relevant `Research/`, test gates, artifact gate, and local owner docs/tests.

## Owner Mapping

Map to exactly one primary owner. Foundation owns product truth and services; contracts/schemas own stable public shapes; facades/providers route controlled access; UI presents and forwards; plug-ins extend through ExtensionAPI; test harness proves evidence and never owns product truth.

## Authority Rules

For every system define owned truth, forbidden domain, published contracts, read-only inputs, accepted commands/work orders, persistence/interchange impact, UI/facade routes, and required proof. Support, UI, AI, integrations, adapters, installers, and tests must not become sovereign over Foundation truth.

## Architecture Rules

O3DE remains authoring host; Unity/Fall of Avalon remain external runtime; neutral canonical handoff crosses engines; Unity owns Unity-native outputs; optional providers fail closed; Mono and IL2CPP remain separate; evidence and permissions remain distinct; no declaration grants runtime or deployment authority.

## Test Obligations

Require local invariants, publisher/consumer boundaries, lifecycle/persistence, malformed/degraded inputs, cross-system consequence, soak risk, and surface-specific tests. Missing lanes are added or reported partial/blocked.

## Hard Stops

Stop when research/owner evidence is absent, protected data would be copied, public/persisted shape or dependencies change without authority, or runtime proof is claimed without evidence.

## Validation

Use owner-specific gates; otherwise report the gap and run the smallest directly applicable command. State `runtime sign-off not performed` when appropriate.
